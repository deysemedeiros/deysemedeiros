### 🎓 Sistema de Monitoria e Frequência Acadêmica — *em desenvolvimento*

**Meu papel:** back-end — API REST em camadas (Controller → Service → Repository), persistência no MongoDB e implementação de **autenticação com Spring Security + JWT** e controle de acesso por perfil (aluno, monitor, supervisor/admin).
