## 🌸 Projetos em destaque

### 🏛️ Osíris · Plataforma de Conexão Acadêmica e Empresarial
> Projeto Integrador da FATEC Zona Leste · equipe de 5 pessoas

Plataforma que conecta empreendedores e pequenos negócios aos alunos de DSM. O empreendedor cadastra uma demanda de software e os grupos de alunos a desenvolvem como projeto real.

**💙 Minhas contribuições (back-end em NestJS + PostgreSQL)**
- 🔐 **Autenticação e autorização** com **JWT** (Passport), senhas com bcrypt, **guards** de rota e controle de acesso por **roles**
- 🛡️ **Módulo administrativo** com CRUD completo e regra de segurança: usuário comum não se torna admin; apenas um admin promove outros
- ✉️ **Verificação de e-mail** com código enviado via **SMTP (Nodemailer)** e integração com **Azure**
- 📦 **DTOs com validação** (class-validator) em todas as entidades
- 🧱 Módulos de **Empreendedor** (com validação de CNPJ), **Coordenador**, **Grupo**, **Demanda** e **Histórico**
- 🗄️ **Migrations** e refatoração da camada de persistência com **TypeORM**
- 📖 **Documentação da API com Swagger**
- 📐 **Engenharia de software:** diagramas **UML com PlantUML** para a documentação do projeto
